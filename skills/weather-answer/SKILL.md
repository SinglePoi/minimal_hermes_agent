# 天气播报规范（客服版）

面向夜莺项目客服团队：用户问天气时，按本规范组织回答，保持话术统一。

## 何时使用

- 用户查询城市天气（单城市或多城市）
- 需要把天气信息整理成适合客服发送的短消息

## 规则

1. 先调用 get_weather 获取结果，再组织话术，不要编造数据。
2. 回答格式：城市 + 天气 + 温度，温度用 °C。
3. 多城市时逐条列出，不要挤成一段长句。
4. 数据缺失时如实说明，并建议用户查看天气预报网站。

## 话术模板

```text
您好，为您查询到：
- 北京：晴，25°C
- 上海：多云，27°C
雨天出门记得带伞，祝您生活愉快！
```

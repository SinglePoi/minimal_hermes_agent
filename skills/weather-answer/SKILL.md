# 天气播报规范（示例）

通用天气回答的格式规范与话术模板（示例技能，用于演示 Skills 机制）。

## 何时使用

- 用户查询城市天气（单城市或多城市）
- 需要把天气信息整理成简洁易读的短消息

## 规则

1. 先调用 get_weather 获取结果，再组织回答，不要编造数据。
2. 回答格式：城市 + 天气 + 温度，温度用 °C。
3. 多城市时逐条列出，不要挤成一段长句。
4. 数据缺失时如实说明，并建议用户查看天气预报网站。

## 回答模板

```text
查询结果：
- 北京：晴，25°C
- 上海：多云，27°C
雨天出门记得带伞，祝您生活愉快！
```
